# Landing Audit

A browser-based, mobile-first checklist for reviewing landing pages across eight UX and conversion categories. It scores 32 practical checks, highlights high-impact gaps and exports a Markdown action plan.

## Run
Open `index.html` in a browser or deploy the repository with GitHub Pages.

## Categories
Value proposition · Visual hierarchy · Content · Trust · Conversion · Accessibility · Mobile · Performance

The score is a structured heuristic, not a substitute for user research, analytics or usability testing.
